# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability in ERP CRM Discovery, please report it privately:

1. Use the **GitHub Security Advisory** tab on the repository (if available) to submit a private vulnerability report.
2. Please provide a clear description of the issue, reproduction steps, and potential impact.
3. We will acknowledge receipt of your report, assess the issue, and provide remediation in a timely manner.

---

## 🔒 Data Sensitivity & Privacy Warning

ERP CRM Discovery is designed from the ground up as an **offline-first** desktop tool. All customer process findings, corporate requirements, and interview notes remain stored exclusively on the user's local device in an embedded SQLite database.

> [!CAUTION]
> When submitting issue reports, screenshots, or logs to GitHub:
> - **NEVER** upload real customer SQLite databases (`*.db`), project exports, or confidential trade secrets.
> - **Redact** all real customer company names, tax numbers, employee names, and proprietary business metrics from screenshots before posting.
